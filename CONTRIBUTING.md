# Como contribuir a este Proyecto

## Flujo de ramas
**Nunca** trabajamos directamente sobre la rama `main` ya que lo consideramos un peligro.  
La forma de contribuir sería creado tu propia rama con la funcionalidad que deseas añadir.

## Mensaje de commit
Seguimos el formato `tipo: descripción`, con los tipos `feat`, `fix`,
`docs`, `style`, `refactor`, `test` y `chore`.  
Somos muy *pro-descriptivos*, que queremos decir con esto, queremos decir que si le pones una descripción al commit siempre sera mas legible.

## Cómo proponer un cambio
1. Crea una rama desde `main`.
2. Haz tus commits en ella.
3. Sube la rama: `git push -u origin nombre-de-la-rama`.
4. Abre una Pull Request en GitHub describiendo el cambio.
5. Espera la revisión antes de fusionar.
